# DataCo Supply Chain — End-to-End Analytics

Аналитический проект по исследованию глобальной сети поставок ритейлера
на открытых данных DataCo Smart Supply Chain.


## О проекте

Взяла сырой датасет по сети поставок ритейлера и прошла полный цикл
анализа: от проверки качества данных до формулировки гипотез,
их проверки и рекомендаций для бизнеса.

Цель — оценить финансовую и операционную эффективность бизнеса
за 2015–2018 гг., найти драйверы прибыли и слабые места в логистике
и работе с клиентами.




## Стек

SQL, PostgreSQL, DBeaver


## Методология

Работа разбита на шесть блоков:

1. Data Overview — размер, пропуски, дубли, диапазон дат.
2. Business KPIs and Trends — выручка, прибыль, маржа, MoM-динамика.
3. Product and Category Analysis — категории, товары, скидки.
4. Delivery and Operations — late risk, отклонения от графика.
5. Customer and Market Analysis — топ-клиенты, сегменты, концентрация.
6. Order Status — распределение статусов, order-level метрики.

Прибыль считала как `Sales × Order Item Profit Ratio`. Так корректнее,
чем суммировать поле Order Profit Per Order, которое дублируется
на уровне заказа и даёт двойной счёт.

## Ключевые результаты

**Общие KPI:**

- Выручка: 36 784 734,31
- Оценочная прибыль: 4 418 272,11
- Маржа: 12,01%
- Средний чек: 559,45

**Главные находки:**

1. **Премиум-доставка не работает.** First Class опаздывает в 95%
   случаев (+1 день к плану), Second Class — в 77% (+2 дня).
   Standard Class работает ровно по плану. Проблема системная,
   не региональная.

2. **Топ-клиент по выручке убыточен.** Customer ID 791 принёс
   10 524 выручки и минус 1 039 прибыли. Это сигнал: нельзя
   оценивать клиентов только по обороту.

3. **Скидки не влияют на маржу.** При росте скидки с 0–5% до 20%+
   маржа почти не меняется. Гипотеза: profit ratio уже post-discount.

4. **Последние три месяца — обрыв данных.** Ноя-2017, дек-2017,
   янв-2018 неполные. Исключать из трендов.

5. **Клиентская база низкоконцентрированная.** Топ-30 клиентов
   дают всего 0,7% выручки. Правила Парето нет.

6. **Ассортимент неоднородный.** Лидеры — Fishing, Cleats,
   Camping & Hiking. Аутсайдеры — CDs, Toys, Strength Training.
   Высокомаржинальные ниши — Women's Clothing, Fitness
   Accessories, Men's Golf Clubs.


## Рекомендации


- Пересмотреть SLA премиум-доставки и провести аудит
  логистических партнёров.
- Найти всех убыточных клиентов и разобраться в причинах.

- Очистить данные для отчётности: исключить неполные месяцы,
  использовать только COMPLETE и CLOSED.
- Уточнить методологию расчёта profit ratio.

- Внедрить RFM-сегментацию и retention-кампании.
- Провести ABC/XYZ-анализ ассортимента.
- Исправить аномалию с Dell Laptop (aggregated SKU).
